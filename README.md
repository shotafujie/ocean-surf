# OCEAN SURF — POINT BREAK RACE

ブラウザだけで動く 3D サーフィンレース。`index.html` 一枚で完結します。

**▶ 遊ぶ： https://shotafujie.github.io/ocean-surf/** （PC / キーボード必須）

## 遊び方

| キー | 操作 |
|---|---|
| `A` / `D`（`←` `→`） | ターン |
| `W` | パンピング加速 |
| `S` | ブレーキ / 深いカービング |
| `Space` | ジャンプ |
| `R` | リスタート |
| `C` | カメラ切替（チェイス / ロング / ボード目線） |
| `F` | フリーサーフモード切替 |
| `M` | サウンド ON / OFF |

7 つのゲートを順に通過してゴールまでのタイムを競います。ライバル 4 人（KAI / NOA / RIO / ZEN）と同時スタート。ベストタイムと区間スプリットはブラウザに保存されます。

**速く走るコツ**: うねりは奥から手前に流れています。まっすぐ突っ切ると波の背を登り続けて失速するので、波の斜面を斜めに滑り続けてください。コースが斜め 62° のジグザグなのはそのためです。

## 技術メモ

- **波** — 4 本のサイン波の合成。まったく同じ式を頂点シェーダー（描画）と JavaScript（物理）で共有しているので、見えている波とボードが乗る波が完全に一致します。
- **物理** — プレイヤーと NPC は同一の `stepSurfer()` を通ります。ハンデや補正はありません。
- **NPC AI** — 11 方向の候補ヨーを評価し、「斜面による加速を先読み時間 T ぶん織り込んだ速度」をゲート方向に射影した値が最大の向きを選びます。技量パラメータで 4 段階の差。
- **サウンド** — 音源ファイルなし。Web Audio API で全て手続き合成。砕波音はプレイヤー周囲の海面を実際にサンプリングして、波が崩れている地点を探して方向つきで鳴らしています。
- **外部依存** — three.js r128（cdnjs）のみ。

## 開発

```bash
npm install     # 検査ツール用
npm run serve   # http://localhost:8000
npm test        # 実行時 / レース / 音声 の全検査
```

設計上の制約や過去に踏んだ落とし穴は `CLAUDE.md` にまとめてあります。

## 公開（GitHub Pages）

`main` ブランチのルートを Source にした Pages で公開しています。`main` に push すれば
1〜2 分で https://shotafujie.github.io/ocean-surf/ に反映されます。

- ビルド工程は無いので、`index.html` がそのままトップページになります
- キーボード必須のためスマホでは遊べません（`pointer: fine` を見て注意書きが出ます）
- three.js は CDN 依存。読み込めない環境／WebGL が使えない環境では、
  黒画面のまま止まらず理由を表示します
